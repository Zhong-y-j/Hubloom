# 入门指南

欢迎来到 Hubloom。

本部分的目标很简单：**让你先跑起来，知道 Hubloom 是什么、能做什么、怎么开始做。**

我们不假设你懂 MCP、A2UI 或任何 Agent 协议——这些会在 [核心概念](../core-concepts/README.md) 里再讲。这里只关心三件事：

1. **Hubloom 是什么** — 一句话说清楚定位
2. **怎么跑起来** — 配置 → 启动 → 发第一句话
3. **怎么写第一个 Skill** — 用最小例子理解扩展点在哪

事件 Webhook、企微入口等进阶能力，等主路径跑通后再看 [进阶功能](../advanced/README.md)。

## 开始之前

你只需要准备：

- 会改 YAML 配置即可（类似改 `application.yml` 那种经验就够；不要求精通 Python）
- 一个可用的 **LLM API Key**（OpenAI 兼容接口即可，如 DeepSeek 等）
- 一个 **Swagger / OpenAPI** 地址（用你自家的业务 API 最好；没有的话，快速上手章节会提供公开示例，如 Petstore 或 GitHub API）

> LLM 需要可用的 Key 才能对话；没有自家 Swagger 时，可先用公开 OpenAPI（如 Petstore）走通链路，再换成你的业务文档。
