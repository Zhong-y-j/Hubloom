# Hubloom 文档

面向**零基础 / 初级**集成方的 AI Agent **基座脚手架**手册。

> 如果说 Spring Boot 是接口地基、Vue Admin 是后台脚手架，Hubloom 就是 Agent 时代的运行时模板：接上 Swagger/OpenAPI，用自然语言在真实业务 API 上办事。

## 怎么读

按侧栏顺序即可：

1. [入门指南](guide/README.md) — 是什么、装起来、跑通第一条  
2. [核心概念](core-concepts/README.md) — 架构与协议（短、有图）  
3. [使用指南](usage/README.md) — 配模型、接 Swagger、写 Skill、嵌入  
4. [进阶功能](advanced/README.md) — 记忆 / RAG / A2A / 事件 / 企微（可选）  
5. [参考文档](reference/README.md) — 查配置、查 API、FAQ  

正文会逐步写满；当前各章是**章节定义（大纲）**，标明「本章要讲什么」，方便我们按页补内容。
