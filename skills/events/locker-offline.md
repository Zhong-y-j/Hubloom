# locker.offline — 离线诊断

## 目标

核实设备当前状态与所属小区信息，给出**可执行的排查建议**（不擅自改配置）。

## 步骤

1. 按 `payload.deviceId` 查询钥匙柜列表/详情，确认是否存在、在线/启用状态、柜名。
2. 若有小区字段：查所属小区是否存在、信息是否完整。
3. 结合工具结果分析可能原因（设备不存在、已禁用、小区缺失、短暂掉线等）——仅基于返回数据，不编造。
4. 交 Respond：现状摘要 + 建议下一步（如现场检查、等待重连、联系运维）；需要写操作时明确「须确认后才能执行」。

## 禁止

- 禁止擅自删除、禁用、改绑。
- 禁止在 401/空列表时假装已诊断完成并给出虚假根因。

## 完成标准

有一版清楚的「查到了什么 / 没查到什么 / 建议谁做什么」。
